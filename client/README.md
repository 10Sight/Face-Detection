# 10Sight Neural Frontend

The visual interface for the Neural Face Detection system. Built for high-performance biometric analysis with a premium "wow-factor" aesthetic.

## 🎨 Design Philosophy

- **Premium Aesthetics**: Dark mode, glassmorphism, and dynamic micro-animations powered by **Framer Motion**.
- **Real-time HUD**: Integrated service monitoring with **Sonner** toast telemetry for biometric uplink status.
- **Neural Visuals**: Custom "Technical Mesh" and "Biometric Assembly" effects visualizing skeleton and face vectors.
- **Enterprise UX**: High-density dashboards optimized for Mission Control environments.

## 📂 Project Structure

```text
client/src/
├── components/           # Reusable UI atoms and Biometric Views (Face, Mesh, Hand)
├── pages/                # High-level views (Control Center, Neural Registry, Analytics)
├── store/                # Redux Toolkit slices and RTK Query API definitions
├── lib/                  # Shared utilities and helper constants
├── assets/               # Scalable graphics and design tokens
└── App.jsx               # Main application Shell and Routing
```

## 🛠 Tech Stack

- **Framework**: React 19 / Vite 6 (Cutting-edge)
- **State Management**: Redux Toolkit (RTK Query for forensic sync)
- **Styling**: Vanilla CSS + Tailwind CSS (Utility-first)
- **Animations**: Framer Motion
- **Networking**: WebSockets + PeerJS (Remote Capture Uplink)
- **Feedback**: Sonner (High-fidelity telemetry)
